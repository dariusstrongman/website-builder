# Website Builder public website

The public GitHub Pages site presents the Website Builder service, original fictional design studies, transparent project packages and an interactive first-look workspace.

The homepage uses one continuous design canvas from the opening through structure, finished design and mobile fit. The first-look sketch responds locally to the brief and supports headline, style, accent and device edits. Existing project reads and submissions remain connected to the Stromation service.

## Verification

Run `node scripts/verify-release.mjs` for route, asset, copy, privacy, interaction and workspace behavior checks. GitHub Actions runs the same command on pull requests and main. Browser checks also cover all 31 routes at phone width, example viewer navigation, the scene gesture, reduced motion and first-look editing.

## Service launch boundary

Publishing this public website does not prove autonomous paid fulfillment. Checkout, website-specific payment entitlement, production automation, revision and delivery still require a separate end-to-end service release. The first look runs without paid generation. Scope and payment are agreed before production.

## Hosting

GitHub Pages serves the static files from the repository root. `project.html`, fictional demos and preview routes remain noindex. Marketing routes use canonical GitHub Pages URLs. No operator or provider credentials belong in this repository.
