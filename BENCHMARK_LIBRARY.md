# Website Builder benchmark library

Updated 2026-09-05.

These are reference sites for principles, not templates. A customer website should never inherit another site's palette, component shapes, layout or brand expression simply because that reference scored well.

## Drawer.ai — added 2026-09-05

**Visual reference score:** ~9.0/10 for look and feel.

Drawer.ai is not the visual ceiling for Website Builder, but it beats more ambitious sites in several useful areas:

- **Restraint:** it knows when a real product visual is enough.
- **Product/UI integration:** screenshots and workflow imagery participate in the composition instead of feeling pasted into marketing cards.
- **Technical density:** specialized information stays readable and calm.
- **Long-page consistency:** section layouts change while the grid, spacing and visual discipline remain coherent.
- **B2B composure:** the site feels mature without needing constant spectacle.
- **Motion discipline:** movement supports comprehension rather than becoming decoration.
- **Grid/spacing polish:** alignment and component proportions remain controlled throughout the page.

### What to transfer

- Let the strongest real artifact carry the section.
- Reduce visual noise before adding a new effect.
- Keep one spatial system even when section composition changes.
- Give dense technical content hierarchy instead of oversimplifying it.
- Use motion only where it makes a workflow/state/relationship easier to understand.
- Treat the transitions between sections as part of the design.

### What not to copy

Do not copy Drawer.ai's palette, electrical-industry motifs, component shapes, exact layouts or brand language.

The goal is **our ambition + Drawer’s restraint**.

## Category-specific routing

References should be chosen because they answer a relevant design question:

- **B2B SaaS / technical products:** Drawer.ai, Linear, Vercel, Attio, Ramp
- **Product-led software:** Gamma, Cursor, ElevenLabs
- **Trust-sensitive consumer/service:** Tend
- **Distinctive brand/product expression:** Clay, Raycast
- **Complex information architecture:** Stripe, Ramp, Drawer.ai

A build may use multiple references, but the creative direction must still pass the logo-removal test: if the customer's logo disappears, the page should still feel specific to that customer's business rather than to the benchmark that inspired it.
